# 🧮 Calculator Web App

Vanilla JavaScript, HTML5, ebong CSS3 diye toiri ekti simple, responsive ebong user-friendly calculator application.

## ✨ Features
- ➕ Basic Arithmetic Operations (Jog, Biyog, Gun, Bhag)
- 🧹 Clear (C) ebong Backspace/Delete functionality
- 📱 Responsive Design (Mobile, Tablet, & Desktop friendly)
- 🎨 Clean UI/UX with smooth button interactions

## 🛠️ Tech Stack
- **HTML5** - Web page structure
- **CSS3** - Styling, Flexbox/Grid
- **JavaScript (ES6+)** - Calculator logic & DOM Manipulation

## 💡 Key Learnings
Ei project-ti toiri korar somoy ami jinisgulo shikhechi:
- JavaScript Event Listeners (`click` events)
- DOM Selection & Dynamic display updating
- String & Number handling in JS logic
- Math evaluation & basic error handling
